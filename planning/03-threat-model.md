# 03. 위협 모델 (Threat Model)

- 작성일: 2026-10-25 / 상태: Phase 0 초안
- 범위: 테스트넷 MVP. 신뢰 경계: ① 인터넷↔API ② 앱↔PostgreSQL ③ 워커↔RPC ④ 워커↔판매자 웹훅 서버 ⑤ 고객 지갑↔컨트랙트
- 자산: 판매자 API 키, 웹훅 시크릿, 주문/결제 무결성, 감사 로그, DB 자격증명, (테스트) 배포 키
- 위험도: 영향×가능성 (H/M/L). 테스트넷이라 금전 영향은 낮지만 **설계는 실자금 가정으로 검증**한다.

## 잔여 위험 / 비범위
- 호스팅 인프라 침해, 내부자 위협, 물리적 보안, DDoS 대규모 방어(테스트넷 MVP 범위 밖)
- 판매자 지갑 키 관리(우리 시스템은 판매자 키를 다루지 않음)
- 규제 위험은 05 문서

## 검증 기준
- 각 행의 테스트 케이스가 Phase 3~7에서 자동화 테스트로 존재하고 통과할 것.
- Phase 7에서 이 표를 체크리스트로 재점검하고 결과를 `docs/security-review.md`에 기록.
