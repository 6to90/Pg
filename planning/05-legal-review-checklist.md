# 05. 법률·운영 검토 체크리스트

- 조사일: 2026-10-25
- **면책**: 이 문서는 법률 자문이 아니며 규제 준수를 보장하지 않는다. 아래 항목은 전문가(변호사, 가상자산 규제 경험자) 검토가 필요한 **조사 목록**이다. 법적 검토 완료 전 메인넷 결제·고객 자금 수취는 활성화하지 않는다. 테스트넷 개발과 영업 개시는 분리한다.

## 3. 운영 원칙 (현 시점 결정)
1. 테스트넷·가치 없는 테스트 토큰만 사용. UI/문서에 "TESTNET – 가치 없는 토큰" 명시, 실자금 오해 문구 금지.
2. 메인넷 chainId와 실제 토큰 주소는 코드에서 차단. 활성화 스위치를 만들지 않는다.
3. 사용자 개인정보는 최소 수집, 테스트 데이터만 사용.
4. 영업 개시 전 게이트: L1~L10 전문가 검토 완료 + 보안 감사 + 별도 서면 승인.
